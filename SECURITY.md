# Signaler une vulnérabilité

Ne pas ouvrir d'issue publique. Deux canaux, à choisir selon la nature du
projet concerné :

- Politique de divulgation de l'État : https://vdp.numerique.gouv.fr/p/Send-a-report
- Signalement privé sur ce dépôt GitHub : onglet *Security* → *Report a vulnerability*
  (https://github.com/lombre33/FormPlus/security/advisories/new).

Un correctif est visé avant toute divulgation publique.
