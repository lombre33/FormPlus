FormPlus

Cette page est un widget Grist. Ajoutez-la dans un document : Ajouter un widget, Personnalisé, URL personnalisée, puis collez l'adresse de cette page. Niveau d'accès : accès complet, nécessaire au concepteur pour retrouver la page et gérer les questions.

Pour répondre à un formulaire hors de Grist (sans passer par une page Grist), utilisez public-form.html avec le lien du formulaire après #form= — ne rend que les champs natifs, pas les questions supplémentaires.

Secours : l'URL du widget peut elle-même contenir le lien du formulaire, widget.html#form=<lien>. Le mode répondant fonctionne alors même sans options enregistrées.
