1. Formulaire principal (Table A)

Le formulaire natif publié qui porte la clé. Table de destination des champs simples et de la référence créée à l'étape 2.

2. Question à choix, lue depuis une autre table en attente

Ajoute une colonne Référence cachée dans la table A, attachée au formulaire publié, pour exposer les libellés de la table choisie.

3. Question conditionnelle, écrite dans une autre table en attente

Visible seulement si la question 2 vaut une valeur précise. La réponse est écrite dans une table différente (Table B).
